## Hi, I'm 연서 — 저는 AI를 "제안"이 아니라 "고객의 시스템 안"에 심습니다

> **"일하는 방식을 더 행복하게"** — Wishket의 미션 아래, **AIDP(AI Delivery Platform)** 사업부에서
> **Forward Deployed Engineer(FDE)** 로 일하고 있습니다.

FDE는 컨설팅과 엔지니어링의 경계에 서 있는 역할입니다. 요구사항 문서를 던지고 끝나는 게 아니라, 고객의 레거시 시스템·ERP·세일즈 툴 안으로 직접 들어가서 **운영 가능한 형태로 AI를 배포**하고, 그 결과를 다시 표준화해 다음 고객에게 재사용합니다.

---

### 무엇을 만들어왔는가

- 🏗 **레거시 현대화** — MSSQL/ASP 기반 온프레미스 ERP를 Supabase/PostgreSQL 기반 클라우드 아키텍처로 마이그레이션
- 🧩 **임베디드 AI 제품화** — 고객사 웹에 그대로 심을 수 있는 위젯형 AI 기능을 설계하고, 한 곳에서 검증한 뒤 여러 프로덕션 환경에 반복 배포 가능한 형태로 일반화
- 🔌 **플랫폼 인증/연동 계층** — 사내 세일즈·운영 자동화 플랫폼의 인증을 토큰 기반부터 MCP 연동까지 단계적으로 고도화
- 🤖 **에이전틱 엔지니어링** — 멀티 에이전트 워크플로우와 MCP 서버를 실제 업무 파이프라인(지식 위키, 사내 자동화 봇, 일정 관리)에 결합
- 📐 **컨설팅 산출물** — 고객 대상 AI 도입 제안서(ISMP)와 조직 온톨로지 기반 지식 위키 설계

### 지금 집중하는 것

### Before AI engineering
